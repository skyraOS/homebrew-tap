# Skyra Homebrew tap

Official distribution of Skyra 0.1.0. Apple Silicon; macOS 14+.

```sh
brew tap skyraOS/tap
brew install --cask skyra
```

Downloads and setup: https://github.com/skyraOS/skyra-releases

Update with `brew update` and `brew upgrade --cask skyra`.
Uninstall with `brew uninstall --cask skyra`; conversations, workspaces and provider logins remain.
Skyra is licensed under FSL-1.1-ALv2.

This release is ad-hoc signed, without Apple Developer ID or notarization. macOS may block first launch; review it in System Settings > Privacy & Security.
